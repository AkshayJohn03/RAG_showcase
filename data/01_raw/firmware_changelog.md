# Helios Firmware Changelog (abridged)

## Helios 4.2 (2026-02-14) — current required release
- Fixed XK-7 rev B jitter above 40C via adaptive timing calibration.
- Added XK-7 rev C thermal profile (rated to 46C continuous).
- Minimum version for Product X warranty claims involving timing.

## Helios 4.0 (2025-09-02)
- Initial XK-7 support (rev B only). Known issue: jitter above 40C (unfixed).
- Units X-101 and X-207 shipped on this release (see Q3 field report).

## Helios 3.8 and earlier
- No XK-7 support. Upgrade path: 3.8 → 4.0 → 4.2 (no direct jump).
